# qa_python
Для проекта реализованы автотесты, которые покрывают основные методы класса:

1. **add_new_book** – проверка добавления книг в словарь, негативные проверки на длину имени и дублирование.
2. **set_book_genre** – проверка установки жанра, смены жанра, попытки установить жанр не из списка.
3. **get_book_genre** – проверка получения жанра книги.
4. **get_books_with_specific_genre** – проверка получения списка книг с конкретным жанром.
5. **get_books_for_children** – проверка получения книг, подходящих детям.
6. **add_book_in_favorites** – проверка добавления книги в избранное и негативные сценарии.
7. **delete_book_from_favorites** – проверка удаления книги из избранного и негативные сценарии.
8. **get_list_of_favorites_books** – проверка получения списка избранных книг.
