# qa_python
Для проекта реализованы автотесты, которые покрывают основные методы класса:

1. **add_new_book** – проверка добавления книг в словарь, включая проверки на длину имени и дублирование.
2. **set_book_genre** – проверка установки жанра книги, смены жанра, попытки установить жанр не из списка.
3. **get_book_genre** – проверка получения жанра книги.
4. **get_books_with_specific_genre_only** – отдельный тест для получения книги по жанру (позитивные и негативные сценарии).
5. **get_list_of_favorites_books_only** – отдельный тест для получения списка избранного (есть книги / пустой список).
6. **get_books_for_children** – проверка получения книг, подходящих детям.
7. **add_book_in_favorites** – проверка добавления книги в избранное.
8. **delete_book_from_favorites** – проверка удаления книги из избранного.

Запуск тестов производится командой:
pytest -v tests.py
